## B alem-env（S1–S7）

- **①测量对象：** 长时程、开放式**多智能体协作**基准。JAX 环境（建基于 Craftax-Coop），程序化生成的同步/交接协作任务、软特化、通信信道与可调协作难度 α∈[0,1]（Easy 0.3／Medium 0.6／Hard 0.9）；93 成就、27 协作目标、9 层地牢、单回合上限 10000 步。同世界暴露 symbolic／pixel／text 三种接口。被测量＝**零样本同构 3-agent LLM 团队**（13 个模型），另以**训练过的 MARL 策略**（IPPO/HyperMARL-IPPO/MAPPO/PQN-VDN，约 25M 参数）为参照；异构混合队列为未排名条目。主指标 Base%／Coord.%／Total%（各自独立归一化，Total% 非前二者之和）。
- **②分数住处：** 论文 **Table 1**（13 LLM 跨 Easy/Medium/Hard 的 Base/Coord/Total 均值＋95% bootstrap CI）及 Fig. 4/5 任务级与消融图；**在线榜单** `leaderboard.html` 的行数据在 **`data/leaderboard.json`**（同构队）／**`data/rl_results.json`**（MARL 基线）／**`data/llm-run-configs.json`**（逐行运行配置），本包**已取到行数据**（非「JS 加载、未取到」）。行字段＝`id／name／config／type／family／params／verified／scores{base,coord,total}[mean,ci_low,ci_high]／harness_version／eval_dates`；**无成本/token/dollar 列**。MARL 表列为 Base/Coord/Total%，训练预算以 100M/1B/10B **环境训练步**分档（非模型参数、非 API 成本）。
- **③成本字段可得性：未公布（有界未发现）**。已读全部来源无美元/API 费用、无 token 用量、无延迟列。相关命中均为**非成本**语义：论文与榜单 protocol 提及「API costs」**仅作减少专有模型种子数的理由**（开放权重 20 seeds／难度，闭源 10 seeds，因 API 成本）；论文 §提示词模板 `Token budget: 8192 tokens for your full response` 与 harness `max_tokens: 8192` 为**单次响应生成长度上限**，非账单；论文 §消融报 `raw_reasoning` 平均 token 数（如 Gemini-Low 198±20 tokens/受控步）为**推理长度度量**，非用量；§1375「costs 1 stone」为**游戏内货币**。**唯一可得的算力口径**：论文 §C.3 称 LLM 实验在 **3× NVIDIA A100 80GB** 上运行，每模型每难度 20 seeds 耗时 **10–30 小时**（硬件/墙钟，非美元）；MARL 训练称单卡 <2 天（模拟吞吐 SPS 在 L40S 上测）。**以上均不得当作 API 实耗或美元成本。**
- **④已发表 multi-vs-single 对照：有，但无成本。** 论文 **Appendix E.1／Fig. 19**：同一底层世界、**同一开放权重模型 Gemma-4-31B-it** 的四设置校准——单智能体 Base 12.8%、多智能体（无角色压力/协作任务）11.4%、加软特化 10.1%、完整 alem(Hard) 7.3%；**单智能体 vs 完整 alem 为 43% 相对下降**（Base 为唯一跨设置可比的奖励类）。原文明确「uses one open-weight model」且仅作 sanity check、相邻 CI 重叠，**不构成组织收益证据**；该对照**不含任何成本列**。此外 §4 有 harness 消融（记忆/通信/推理）与异构队「接近成员平均、未达最强成员」的描述性结果，均非同模型 multi-vs-single 双数字。仓库侧提供 `Alem-SingleAgent-Symbolic`（标注 experimental）单智能体变体，但**未附与之配对的公开分数/成本数字**。

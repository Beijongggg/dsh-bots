## 2. 为什么分开训练和测试仍可能不够

CT §4.1区分选择准则的偏差与方差。某候选的验证分数即使无偏，有限样本噪声仍能被
反复选优利用。§4.2用小验证集展示这一点，并明确说已被直接最小化的验证误差
“should not be used for performance estimation”。因此，选出最高分后继续把这同一分数
当作未参与选择的性能估计，存在选择偏差；文件夹名叫test不改变它的用途。

DS p636指出，只要下一轮分析利用了上一轮保留集结果，新统计量就不再独立于保留集。
这不要求看见原始答案。分数、错误类型或是否晋级都可能进入下一次选形或调参。
后三种反馈映射到 Pod 是项目推断，不是该论文做过组织实验。

DS p636直接讨论预登记整个分析协议，以及在反馈已被使用后“collect new data for a fresh
holdout set”；p638再次限定为函数依赖既往验证结果的情形。DG §1 p2进一步指出，只报告
多个候选中的赢家、按既往结果停止和人工选择都会带入数据依赖。因此独立确认有直接原理
依据；Pod 的晋级轮次、失败日志格式及换题流程仍是本项目设计候选。

普通隔离能让未接触确认数据的既定候选在独立同分布样本上接受评估。它不能自动抵消
反复查看反馈后选赢家的偏差，也不让小样本变得精确。CT §5的原则是把训练与模型选择
视为一个完整拟合过程，§5.1在每个外层评估内部重新进行选择，而不是把已挑好的参数
跨外层评估复用。若又按外层结果改流程，外层本身也参与了选择。

### 不同数据用途能支持什么

以下分工为项目推断，依据是CT §5.1与DS p636的独立性要求，不是已接受的Pod协议。

| 用途 | 可支持的结论 | 边界 |
|---|---|---|
| 开发与诊断数据 | 已见任务上的调试结果、失败类型及改动线索 | 被用于选形、调提示或调阈值后的分数不作独立确认 |
| 保留数据 | 事先固定候选的外部检查，或经有保证的受限机制处理的自适应查询 | “保留”不是永久属性；一旦反馈影响下一候选，就必须按复用协议解释 |
| 晋级确认数据 | 对已冻结候选和比较协议的独立检查，含失败及不确定性 | 同一确认结果反复用于改候选、改门槛或“重试直到过”后，不再是原意义的独立确认 |
| 冻结回归样本 | 已列契约、边界和历史错误仍否保持 | 适合持续重跑，但不能单独代表未来一般任务的期望收益 |

## 3. 防护的保证分别到哪里

### 3.1 Thresholdout

DS p637给出机制概述。DG §4.1的算法对训练集和保留集的统计量均值作带噪差异检查：
差异未超阈值时返回训练集均值，超阈值时返回加噪保留集均值并扣减预算，预算耗尽后
不再回答。这不是把保留集结果原样返回，再给查看次数贴一个预算标签。

DG Theorem 25要求保留集是从固定分布P独立同分布抽取的n个样本，查询函数取值在[0,1]，
由机制提供全部保留集访问。误差τ、失败概率β、总查询上限m和过拟合预算B共同决定
阈值、噪声与样本量条件；定理中的保证还带有过拟合计数 `Z_i < B` 条件。不能只拿
“可复用”三个字允许无限查询，也不能把B等同于任意设定的普通查看次数。
其中 `m >= B > 0`，定理的参数和样本量下界须成套满足。
本次核查条件与原文，不替Pod选参数，不对独立性未知的任务直接套数值保证。

### 3.2 Ladder

BH §1.3的样本来自固定分布D，损失在[0,1]。Algorithm 1用固定步长η，只在分数足够
改善时发布经舍入的新分数，否则保留旧最佳值。Theorem 3.1在其条件下给出高概率的
leaderboard error界，按适当η可达 `O((log(kn)/n)^(1/3))`，k为提交数、n为样本数。
该误差为各轮“截至当前的最佳真实风险”与发布值之差的最大绝对值，不是单侧界。
它不保证每个候选都有准确分数，
也不是对任意晋级规则的一般保证。

§4的parameter-free版本使用适应步长。§4.1明确说其显著性检验 “primarily heuristic”：
自适应选择后Student近似一般不再有效，且没有处理多重比较。固定步长定理不能直接
借给这个版本，更不能借给普通“每次提高一点且p值过线就晋级”的流程。

## 4. 风险与防护对照

防护均为供HITL选择的候选。失败留痕、曝光账及版本登记是为实施原理提出的项目方法，
不是这些论文已测试的Pod实现，也不因记录完整就恢复统计独立性。

| 风险ID与场景 | 失败方式与原文依据 | 防护候选 | 生效前提 | 不能保证什么 |
|---|---|---|---|---|
| R1 反复选优 | 有限样本噪声被候选搜索利用；CT §4.1、§4.2、§5.1；DG §1 p2的只报赢家问题 | 将选形、提示、阈值和失败候选计入完整选择过程；开发／外部评估分工；可行时作嵌套评估 | 评估外层不再参与该次选择；候选与预算可追溯 | 仅保存赢家日志或只增加重复次数不能消除选择偏差；嵌套评估仍有方差和开销 |
| R2 反馈曝光 | 下一候选依赖同一保留集结果；DS p636–638、DG §4.1；BH Algorithm 1 | 登记谁看到何种反馈；独立新确认集，或评估Thresholdout／固定Ladder式受限反馈 | 新集独立且代表目标；或访问只能经过符合条件的机制，满足样本与预算要求 | 隐藏答案但公开精细分数不自动安全；普通限次或脱敏不继承上述定理 |
| R3 晋级确认 | 反复按确认结果改候选、改阈值或重试直到通过；CT §5、§5.1；DS p636预登记；DG §1 p2停止依赖；BH §4.1 | 冻结候选与比较协议后独立确认；登记所有试验、失败和停止原因；再修改就声明新一轮选择 | 判据、数据用途及停止规则在结果前确定；确认时仍具独立性或受控适应保证 | 单次最高分、未调整的逐次显著性或Ladder发布值都不自动授予晋级 |
| R4 题集更新 | 已曝光题继续充当“新测试”，或按结果删题后跨版本比较；DS p636及p638的fresh holdout要求；BH §1.3；CT §5.1 | 曝光题保留作回归；新确认题登记来源、抽样及版本；分列旧集／新集结果 | 新数据相对本轮选择独立；新旧分布或筛选规则可说明 | 新题不一定独立或有代表性；换题不修复旧结论，不保证应对真实分布漂移 |

### 有出处的失效情形

1. CT §4.2、Figures 4–7使用64样本验证集、100次随机验证集实现。平均准则近似无偏，
   但不同实现选出不同超参数；被最小化后的验证误差偏乐观。原文是核方法实验，
   不能把64当作Pod需要的样本阈值。
2. DS p638及Figure 1令标签与特征无关，真实准确率不超过50%。训练与保留集各n=10,000，
   d=10,000；利用保留集筛选500个变量后，作者报告训练及保留分数超过63%，但这不是真实
   泛化能力。图示为100次独立执行的均值与标准差。原数据分区存在，反馈复用仍足以失效。
3. BH §4.1的parameter-free显著性检验在后续自适应候选上不能照用普通Student近似，
   也未控制多重比较。这是作者给出的限制，不是本项目实测它必然失败。

## 5. 前代规格如何承继

以下为项目推断，前代[org-v2规格](../../org-v2/spec.md)只读，旧验收语义不变。

| 前代条款 | 对vNext结论范围的影响 | 留待下游选择 |
|---|---|---|
| §J每岗位1–3个冻结样本，定位为契约回放 | 能证明这些契约样本是否继续通过；样本会被反复查看，不能仅凭通过把一般能力或经济性推广到新任务 | 评测票决定是否另外设代表性评估和独立确认数据，不取消契约回归 |
| V-B1的3–5任务、裸跑失败才入集、成功出集 | 入集已按基线结果筛选，只能直接报告该子集上的条件结果；一般任务收益需要另一个抽样问题。一次裸跑失败也可能受随机采样影响，不证明基线稳定无能 | 评测票决定基线重试、筛选记录及代表性样本；不反改旧入集记录 |
| V-B2同模型、同基础工具、无组织命令、预算同量级 | 控制两臂资源回答比较问题，但不会消除按失败筛题或反复选提示造成的偏差 | 强单代理、多采样、预算消融仍由成本研究与评测票处理 |
| V-B4的四分量token、墙钟、轮次及预登记件 | 原始用量和预登记仍可承继；赢家的一次运行不能代表整个选择过程的开销 | 演进票按成本定义记录探索失败、搜索和确认开销；数值由用户填写后冻结 |

### 不应混为一类的三个问题

- 反馈适应：当前候选依赖先前评测结果。CT、DS、BH直接研究此机制；不同文件或新进程
  不抹去开发者与候选已得到的信息。
- 预训练污染：任务或答案在当前评估前进入模型训练资料。这是不同的来源问题，本文
  三组材料没有核实任何当前模型的训练数据；限制本轮反馈不能证明没有预训练污染。
- 真实分布漂移：目标任务、工具环境或时间段的分布发生改变。DG与BH上述保证依赖固定
  分布，不能直接支持漂移后的性能。重新采样是否覆盖新目标分布仍需另外说明。

小样本的直接依据是CT §4.4：作者指出样本较小、待调超参数较多时，模型选择过拟合
可能最严重。这不提供Pod的最低样本阈值。多次重试和长周期任务的迁移则是项目推断：相同任务重跑
增加该任务上的尝试，不增加独立任务数；共享状态、连续环境变化与任务间依赖可能破坏
现成i.i.d.假设，需要逐项检查。这是由原文前提推导的限制，不是已测出的Pod效应。
选择采样单位、分组／时间窗口及
可推广的任务范围归评测票；缺少这些定义时，不输出自动晋级保证。

## 6. 盲区与关闭边界

- 未复现实验、未测Pod收益、未量化组织选形中偏差的大小；本文只完成机制和适用条件研究。
- Science supplementary未获取，正式参数保证引用的是已独立读取的DG v2，不冒充同篇补充材料。
- 没有证据给出Pod通用的最小样本数、换题周期、分区比例或查看上限；本票也不选择这些数值。
- 未核当前模型预训练污染，未测漂移环境。两者与反馈适应的区别已说明，不能用本文替代专项证据。
- 失败日志、曝光登记和换题留痕只是可审计的候选方法，未在Pod实现。四类风险已有正文依据，
  算法适用限制已明确；是否采用算法、设计何种确认流程仍是下游HITL决议，不属于本票待采集缺口。

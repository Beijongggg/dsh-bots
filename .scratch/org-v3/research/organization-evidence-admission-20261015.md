  随后确认仅对本票执行重新认领、范围修订、Answer、地图索引、关闭及相关文档提交／普通推送；不合并主分支、不改其他研究票或运行面。

## 1. 范围调整，不是全部原判据通过

本票的交付目标调整为：**用已核的有限事实与明确标注的设计推断支持后续形态决策，不再完成原谱系每篇原件、每个头条数字的穷尽复核**。
网络反复不可达、且不承担保留结论的材料停止获取；其他尚未核验的非必要主张也退出本图证据准入，但不假称它们都因网络失败。
原报告、补件和历史评论保留，读取以当前票面 Answer 与本清单为入口。这不是将 S4 判绿，而是用户授权缩小原问题及关闭范围。

- **保留的实证主张**：仍须有已读一手定位、原任务／配置、单位与适用边界；作者报告不等于独立复现。
- **背景与候选机制**：可作为概念说明或设计推断讨论，不要求每个概念均补到原件；不附未经核实的精确效果、费用或普适定律。
- **不准入项**：缺失分母、来源冲突、未读正文及纯题录不能支撑具体性能、成本、阈值或因果结论。删除主张的证据用途，而非删除历史记录。
- **停止补采**：本票不再以原十形态剩余来源、会议归属、每个头条数字或完整作者账单为待办。未来选择确实依赖某项时，在相应决策／实验中显式登记所需证据，不自动重开全谱系。

## 3. 未核材料如何退出关闭范围

| 情形 | 当前处置 | 仍不允许的写法 |
|---|---|---|
| 已记录获取失败 | AdaptOrch 官方仓库两入口404，Semantic Scholar限流、部分官网／JS页面不可读等，不再为非必要背景反复重试；已有可读论文与已核表格照用 | “网站不存在”“没拿到原件所以没有研究” |
| 未读或仅题录 | 原十形态其余候选、部分相变理论、Cognition后续引文、扩展成本／失败数字退出准入；需要时只能作为未核线索 | 将“未核”全部归因于网络，或直接采用原稿数字 |
| 已读但冲突未决 | AdaptOrch分母、MANTA token口径、AgentConductor单位、MACA聚合、Kim计费分母等保留已核部分并点名限制；不再要求作者澄清才完成本票 | 挑一个分母当真、将未报切换费记零、把冲突当造假证据 |
| 目前没有项目实证 | Pod完整切换账、净收益校准、迁移恢复与失败成本由后续规格给待测判据，不在本研究阶段运行实验 | 用外部论文的部分路由费替代项目全账，或把待测设计写成已验证 |

## 4. 原九问的交付口径

| 原问题 | 限定后的交付与未接受部分 |
|---|---|
| ① 十形态原则／适用／成本 | 结构候选与已核子集足够进入讨论；不再要求每形态的每篇原件或同基准成本；未核成本／优劣不用 |
| ② 自适应工作族 | 十二候选指定机制与对照已核，按各补件限制消费；其他题录不补采、不冒充已核 |
| ③ 相变／临界／自组织文献 | 已核机制可谈，未核理论只作待定概念；不再要求补齐每个定理或临界常数 |
| ④ 成本经济 | 已有可复算原值与单位限制；完整总账未知限制结论，不再作为本票关闭前置 |
| ⑤ 失败分类／协议可修性 | 可用分类作候选检查，修复效果与因果充分性未证；未核百分比和全称修复主张退出 |
| ⑥ 反向证据 | 强单代理与有条件收益已提供；不再获取每篇行业原文，“一万agent”不用，不据未经核验引文约束架构 |
| ⑦ 不可能三角 | 有界未定位，保留非全称限制；项目若采用则显式作为假设 |
| ⑧ 强基线与预算 | 现有表及三源补核就绪；预算不匹配与完整账未知如实列明，不宣称等预算纯组织净收益 |
| ⑨ 拒判／回退／校准 | 已读范围的正面字段与有界未报告结论就绪；Pod策略、校准与阈值留给相应HITL票及后续实验 |

## 5. 本次边界

收口只解除本研究输入的排程阻塞；不等于采纳动态选形、学习型路由器、任务内切换、特定编制或破坏性重建。
S2沿此前有限实测判定；S1只约束实际采用的实证主张，S4不再要求被排除主张补采；其他研究票的S1–S5与既有冻结规格不变。
本轮不新增实验、联网原文获取、产品改动、运行面写入或全图证据豁免。

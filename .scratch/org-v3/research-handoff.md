## 每条证据的最小字段

| 字段 | 必填内容 |
|---|---|
| 主张与用途 | 本包内稳定 ID、待证原句、所属关闭项及下游票；一行只支持一个结论 |
| 来源定位 | URL、作者或机构、版本或 commit、采集日期；页码、章节、表行或源码符号；本地快照路径与 SHA 若已保存 |
| 实读层级 | 全文、摘要、书目、官方数据或原判据允许的权威二手；给最短支撑摘录或表格单元格 |
| 证据结论 | 支持、反驳、有界检索未发现、未核验或冲突未决；记录限制，访问失败归未核验 |
| 作者与项目边界 | 作者报告、独立算术复算、项目推断分别标注；本轮无独立实验复现，不把论文报告写成项目已验证 |
| 量化附项 | 两臂的模型、版本、工具、任务集及分片、尝试数与成功数、预算和采样策略、计量单位与分母、聚合与不确定性、原数字和算式 |

非量化条目将量化附项标为不适用，不编造数值。量化来源缺字段时逐项标未知，
不能填零。成本另标公布值或账单复算，说明 token 字段包含关系、价格日期、失败重跑、
路由、搜索与筛选开销。百分点、相对百分比、token 倍数和美元倍数分别记录。

补核件末尾给「原关闭项覆盖表」与「剩余缺口」。有界空结果附检索词、官方入口、
检索日期、已读范围与失败路径，只对这个范围下结论。原判据没有空结果退路时，
空结果能结束工作包，不能关闭票。来源冲突并列记录，主会话裁决后才统一结论。

## 验收与返工

1. 主会话核对实际返回内容和落盘件，工具调用成功只代表会话结束。首包逐条回读原文；
   后续包中支撑关闭、S2/S3、因果比较或争议项的证据同样逐条核验并独立复算。
   其余背景项可抽检，发现同类错误则退回该类条目，不把抽检写成全量核实。
2. 以本次失误作拒收反例：不同模型榜单比不能满足同模型组织对照；摘要未提某词不能
   证明正文无该机制；一次路由开销不能代替完整迁移成本；算术比正确不能证明账单正确。
   任一命中，受影响结论不进入 Answer。原始来源仍可保留为线索。
3. 核对同一数字和 C1–C9 等引用在报告、Answer 与消费者中的含义一致，再整合报告。
   验收记录写明通过项、拒收项、证据路径与未核项；整合由主会话完成，不由采集方自验收。
4. 机械路径或格式错误在本地修。语义问题最多做一次有针对性的返工，且重派与验收仍须
   比接管更省工作；再犯、需重做推理或遇核心资料不可达时，主会话接管或保留缺口。
5. 关闭研究票前逐条回到原关闭判据与 S4，核心未核、冲突未决即保持开放。
   合法空结果只沿该票原有退路处理。主会话登记 Answer、关闭状态与地图指针，
   研究人员的完成声明不触发自动关票。

每包记录实际模型、工具模式、session_id、用时、可得的 token 用量、返工次数和验收结果。
主会话另记交接与核验开销；未计量项标未知。没有同任务本地基线时不报告净节省。

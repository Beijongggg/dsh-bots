## Question

动态组织形式的一手证据面：①各组织形态（单代理优先／supervisor／层级／扁平对等／黑板／市场／
蜂群／动态编组／投票／矩阵）的原则、适用条件与**实测成本/质量**；②**运行时选形、生成、路由、
搜索拓扑**的工作族（MASS／AFlow／AgentSquare／GPTSwarm／DyLAN／MasRouter／AgentPrune／ScoreFlow／
EvoAgent 及 2026 后继）：到底什么在自适应、切换信号是什么、相对固定形态的实测增益、切换成本；
③围绕 LLM 多 agent 使用「相变／临界／序参量／自组织」语言的文献，区分**实测**与**类比修辞**；
④成本经济：相对单代理的 token 倍数、上下文隔离的节省、编排开销、单代理优先的边界；
⑤失败分类学（MAST 及其后继）与哪些失败是协议可修的；⑥反向证据（「1 万 agent 贡献不到 10%」、
Cognition「writes stay single-threaded」「map-reduce-and-manage」）的一手出处；
⑦「不可能三角」是否有真实一手表述（有则引原文，无则明写查无——**空结果也是结论**）。

## Answer

### 阶段性结果，尚待补核

2026-10-13 校正。原报告是研究输入，本票尚未达到关闭条件。

- AdaptOrch v1 的 Table 2、Table 4 确有动态选形及固定形态对照。摘要的 12% 至 23%
  对应相对 Single Best 的增益；SWE-bench 的 fixed-hybrid 消融为 49.8 到 52.6，差 2.8 个百分点。
  预算匹配 Self-MoA 为 51.5 到 52.6，差 1.1 个百分点。各对照不能合称「相对最强静态提升 12% 至 23%」。
- 同文报告每任务路由小于 50ms、合成调用约 $0.01/实例。离线阈值搜索摊销、任务内失败重路由和
  状态迁移的独立成本未核实。500 实例与 85% 测试分片的分母冲突、代码仓本次 404 均限制引用强度。
  这是作者实验报告，不是独立复现。完整定位见[关键引用纠正 §1](../research/evidence-corrections-2026-10-13.md#1-adaptorch-存在可定位的动态与固定形态对照)。
- LUMEN 的阶段差异、同质工作流编译进单代理等结果可作候选对照，须带原任务、模型和预算条件。
  单篇的约 45% 阈值不能直接移作 Pod 切换常量；「加 agent 不省钱」也不是已证普遍结论。
- 「不可能三角」与「1 万 agent 贡献不到 10%」在原报告记录的有界检索中未找到可引用来源。
  前者如沿用，标为本项目表述；后者在补得出处前不用。该空结果不等于全领域不存在。
- 成本数字由[带成本的公开基准与成本口径](02-research-benchmarks-with-cost.md)统一复核。
  原报告的 $3.56 到 $21.75 是约 6.1 倍；3.24M 到 321.8M token 才是约 99.3 倍。
  「无人做过受控 multi-vs-single」撤回为本轮尚未核得满足既定控制条件的对照。

# Research: 组织形态谱系、动态架构（相变）与成本经济

Type: research
Status: ready-for-agent
Deliverable: `../research/multi-agent-organization-landscape.md`

## Question

动态组织形式的一手证据面：①各组织形态（单代理优先／supervisor／层级／扁平对等／黑板／市场／
蜂群／动态编组／投票／矩阵）的原则、适用条件与**实测成本/质量**；②**运行时选形、生成、路由、
搜索拓扑**的工作族（MASS／AFlow／AgentSquare／GPTSwarm／DyLAN／MasRouter／AgentPrune／ScoreFlow／
EvoAgent 及 2026 后继）：到底什么在自适应、切换信号是什么、相对固定形态的实测增益、切换成本；
③围绕 LLM 多 agent 使用「相变／临界／序参量／自组织」语言的文献，区分**实测**与**类比修辞**；
④成本经济：相对单代理的 token 倍数、上下文隔离的节省、编排开销、单代理优先的边界；
⑤失败分类学（MAST 及其后继）与哪些失败是协议可修的；⑥反向证据（「1 万 agent 贡献不到 10%」、
Cognition「writes stay single-threaded」「map-reduce-and-manage」）的一手出处；
⑦「不可能三角」是否有真实一手表述（有则引原文，无则明写有界检索未发现）；
⑧强单代理、单代理多采样与强固定拓扑的预算匹配对照，分清组织收益和额外采样收益；
⑨陌生任务与分布漂移下，选形置信度、拒判、回退及净收益校准有哪些实证与适用限制。

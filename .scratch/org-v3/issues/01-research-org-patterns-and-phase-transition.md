## Question

动态组织形式的一手证据面：①各组织形态（单代理优先／supervisor／层级／扁平对等／黑板／市场／
蜂群／动态编组／投票／矩阵）的原则、适用条件与**实测成本/质量**；②**运行时选形、生成、路由、
搜索拓扑**的工作族（MASS／AFlow／AgentSquare／GPTSwarm／DyLAN／MasRouter／AgentPrune／ScoreFlow／
EvoAgent 及 2026 后继）：到底什么在自适应、切换信号是什么、相对固定形态的实测增益、切换成本；
③围绕 LLM 多 agent 使用「相变／临界／序参量／自组织」语言的文献，区分**实测**与**类比修辞**；
④成本经济：相对单代理的 token 倍数、上下文隔离的节省、编排开销、单代理优先的边界；
⑤失败分类学（MAST 及其后继）与哪些失败是协议可修的；⑥反向证据（「1 万 agent 贡献不到 10%」、
Cognition「writes stay single-threaded」「map-reduce-and-manage」）的一手出处；
⑦「不可能三角」是否有真实一手表述（有则引原文，无则明写查无——**空结果也是结论**）。

## Answer

**结论（2026-10-13；子代理采集 2,070 行交付 ＋ 建图会话判读，未逐条复核数字）**

1. **「不可能三角」＝空结果**。没有任何一手来源给 multi-agent 合作命名过由「组织特性＋LLM 特性」推出的三角；
   四组候选轴（成本/延迟/质量、能力/可控/成本、自主/可靠/成本、效率/柔性/合法性）都无具名 trilemma；
   arXiv 上 `iron triangle`／`impossible triangle` 相关命中为零。最近的形式化结果（arXiv 2605.11672）
   **自述是关于单个 LLM 的猜想**。文献实际支持的是**预算匹配的分解结论**：同质 MAS 的增益主要来自
   额外采样与额外 token 支出。→ 若 v3 继续用这个词，它是**本项目提出的表述**，规格里不得写成文献共识。
2. **「一万个 agent 贡献不到 10%」查无来源**：Project Sid 全文 `10,000` 零命中，一手二手皆无。该工作真实事实＝
   10–1000+ agent 声称、**结果报告在 500 agent**、>1000 agent 运行因**算力**失败。**禁令：不得引用**。
3. **「相变」有实测先例，但只是相位反转、不是按需选形**：LUMEN（arXiv 2606.28362）——
   *"multi-agent design hurts screening but is essential for extraction"*，5.7× 可汇总分析数，
   **逐相成本公开**（$19–$29，中位 $22.65），且**模型排名不跨域迁移**。理论上按任务相变早有尖锐形式
   （arXiv 2601.17311：证明 amplification–collapse 相变、给出预算化协同的精确条件、star/chain/tree 风险的闭式、
   显式预算阈值）——**但仅在合成仿真中验证**；经验上相变**未被确认**：一项仔细检验发现交叉行为
   *"incompatible with"* 2D Ising、结论为 *"field-driven crossovers instead of genuine phase transitions"*，
   另一项自报与其理论「mixed」。**可迁移的是阈值**（预算；单代理准确率 ~45% 天花板；验证剂量-延迟在延迟 2 时
   为黄金分割反比；有效团队规模；角色库语义重叠），**不是临界性**。
4. **公开面已具备给组织定价的基础设施，但无人做过受控的 multi vs single 对照**：Terminal-Bench 4.0
   （USD＋四类 token＋s/trial，330 trials/row）、HAL（USD＋Pareto 标签）、SWE-bench Verified（$/instance＋
   cost-limit 图）、Vals AI（Cost/Test）。最佳单点＝**同为 58.18% 的两行 $634.24 vs $3,267.18**；同模型 effort
   sweep 非单调（Opus 5 max 比 xhigh **差 2.12 分**且成本相近）。除 Anthropic 内部评测（+90.2%、15× chat token、
   token 解释 80% 方差）外，**未找到任何同时含分数与成本的 multi-agent vs single-agent 公开结果**。
   → 该空缺本身是 Pod 可公开补的位置。
5. **最便宜的「组织」常常不是团队；自适应的成本是全场最大的洞**：把同质工作流编译进单 agent＋共享 KV cache →
   精度相近而 **−54% token、−50% 延迟**（arXiv 2601.04748），但选择会越过容量阈值 N*≈83.5–91.8 后崩塌，
   驱动因素是**角色间语义重叠**而非角色数量（最大角色库下 unique skills 仍 100%；每加一个 competitor/skill −7–30%）。
   搜索成本跨**两个数量级**（$3.56→$21.75/dataset；3.24M→321.8M token），而**声称增益最大的系统
   （MANTA／FlowMAS／MACA／AgentConductor）一个都没报自适应成本**；**逐任务切换开销几乎无人报告**。

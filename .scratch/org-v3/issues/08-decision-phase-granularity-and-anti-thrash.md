# 相变粒度与防抖闸门

GitHub: https://github.com/Beijongggg/dsh-bots/issues/11
Type: grilling
Blocked by: 01, 06, 10

## Question

①**粒度**：任务级／任务内阶段级（研究相→实施相→复核相）／会话级——哪几级要，会话级为何做或不做。
②**防抖闸门**：冷却期、最小预期收益阈值、单任务相变次数上限——各自的可执行判据形态。
③**切换成本采集**：相变开销（上下文重建、实例换手、状态迁移）在哪测、如何归账，
如何映射到[「划算」判据与门槛口径](10-decision-cost-worthiness-criterion.md)产出的「成本定义」。

## 关闭判据

- 粒度裁定：每级给「切换触发点／切换对象／不切换的代价」。
- 三条闸门各自写成可执行判据形态（数值留空并标「用户域，fail closed」）。
- 切换成本采集表成文：观测位置、费用分量、去重键、归账位置逐项映射到「划算」票 Answer 的
  「成本定义」，不另立分母或主指标。发现缺项先回修生产者，再关闭本票。
- 给出本项目切换开销的测量形态，而非本轮运行实验。区分任务前路由、任务内重路由、状态迁移；
  明列 cache 创建／读取、上下文重建、实例换手及失败重跑的归账方式。
  AdaptOrch 已报告部分路由和合成开销，但不能代替本项目完整切换账。
- 切换失败与回退的延迟、人工介入、复核代价逐项映射到同一「成本定义」，
  机器用量、人的主动工时和等待时间分列；本票不另设折价或尾延迟统计口径。

## Comments

### 2026-10-13 成本定义生产者确定

原票与「划算」票互相要求口径一致，却没有生产顺序。现由「划算」票先产出唯一成本定义，
本票依赖并给出采集映射。撤销「无人报告」及强制采用某主指标的研究推断，粒度与闸门仍待裁定。

### 2026-10-13 承接非美元代价

切换采集覆盖失败与回退后的时间和人力，不把美元或 token 当作全部代价。
新增字段仍由「划算」票定义，本票只负责映射。

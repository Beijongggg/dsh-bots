# 「划算」判据与门槛口径

Type: grilling
Blocked by: 02, 09

## Question

把「额外消耗的 token 是否划算」写成可执行判据：①三态——**能力不降**（同集分数 ≥ 裸臂）／
**经济**（token ≤ 预登记倍数 × 裸臂）／**稳定**（重复跑方差可控）；②主判据是**帕累托占优**
（同分更省／同成本更高分）还是单一倍数门槛（倍数会误杀「多花 3× 换分数大涨」的划算情形，
B 组 TK-1 即此类）；③对照臂定义（同模型裸实例，沿 org-v2 口径：同基础工具面、无组织命令）；
④数值门槛（预算 B、倍数、方差阈值）——用户域，先留空并 fail closed；⑤与相变成本口径同一份定义。

## 关闭判据

- 判据文本可执行：每条给「判什么／怎么算／数据从哪来／谁执行」；数值空缺项单列并标「用户域」。
- 至少一条**反例夹具**口径：证明判据非恒真（例如「组织分数更高但成本爆炸」必须判不通过）。
- 与 08 号票的成本口径逐字一致（同一份定义）。

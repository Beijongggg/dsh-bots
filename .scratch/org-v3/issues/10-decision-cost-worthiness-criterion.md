# 「划算」判据与门槛口径

Type: grilling
Blocked by: 02, 09

## Question

把「额外消耗的 token 是否划算」写成可执行判据：①能力、经济、稳定三类分别怎样判；
②主判据如何选：帕累托占优、质量下限约束的成本倍数、固定预算得分或每成功任务成本，
各自处理「多花 3 倍换分数大涨」与零成功情形的方式；③对照臂沿评测票的「评测协议」，
保留 org-v2 裸实例基线的继承关系，并讨论强单代理、多采样与强固定拓扑的比较，
登记组织处理与保持不变的控制条件；
④数值门槛（预算 B、倍数、方差阈值）属用户域，先留空并 fail closed；
⑤本票产出唯一「成本定义」，供相变防抖、持续演进和重建范围引用；
⑥尾延迟、人工介入与复核代价作为主指标、约束还是分列观察，如何取舍。

## 关闭判据

- 判据文本可执行：每条给「判什么／怎么算／数据从哪来／谁执行」；数值空缺项单列并标「用户域」。
- 至少一条**反例夹具**口径：证明判据非恒真（例如「组织分数更高但成本爆炸」必须判不通过）。
- Answer 中单列「成本定义」，明确计量对象、单位、调用去重、缓存及失败重跑、编排与搜索摊销、
  分母和零成功处理；数据缺失显式标未知。候选核算式取自成本研究，主指标由本票 HITL 裁定。
- 「成本定义」作为[相变粒度与防抖闸门](08-decision-phase-granularity-and-anti-thrash.md)、
  [持续演进回路与融合通道](11-decision-evolution-loop-and-fusion-channels.md)和
  [重建范围：继承／修订／重写](12-decision-rebuild-scope.md)的引用入口；后位票只补采集与应用映射。
- 对照设计引用成本研究 §4 的 C1–C9。组织提示、角色与控制流是处理变量，不因它们不同就判为不可比；
  外部榜单未控差异不归因为组织效果。
- 对照臂使用评测票 Answer 的「评测协议」，不同基线的增益分别报告；
  多采样的搜索、候选筛选、验证和校准开销纳入成本边界，预算未匹配时限制归因。
- 「成本定义」消费成本研究 Answer 的「非美元代价」，明确尾延迟的样本与分位、失败／超时处理、
  人工介入次数与主动工时、机器和人工复核的归账及去重。各单位先分列，选择折价时须显式给出
  假设并经 HITL 裁定，未知项不填零；质量提高但尾延迟或人工负担恶化须能单独判读。

## Comments

### 2026-10-13 消除互等与预裁定

本票先产出成本定义，不等待防抖票另定口径；发现采集缺项按后位反馈回修。
研究只能提供主指标候选，原「必须 cost per successful task 加 Pareto」不构成用户裁定。
本次仅明确生产顺序与引用位置，未选择经济主判据、数值门槛或实验结果。

### 2026-10-13 接受强基线与非美元代价

「划算」不只比较裸实例与调用费用。新增对照与时间／人力字段由上游研究和评测协议提供，
本票仍是唯一成本定义生产者；没有预选折价、权重或新的通过门槛。

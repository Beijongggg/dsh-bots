# 团队记忆与知识层

Type: grilling
Status: resolved（2026-09-16 用户 round 1 八问全裁「无异议」＝按推荐授权）

## Question

跨回合/跨会话的组织记忆：岗位私有记忆、团队共享上下文、知识库（现 MVP）
三者的边界、写入/失效/晋升规则、在任务生命周期中的位置（handoff 工件与
记忆的关系——什么进票据、什么进长期记忆）。

## 来自 05 号票的输入（2026-09-11 裁定）

- **关闭与归档**：关闭前置＝判据通过＋复核点闭合＋产出登记（谁产出谁登记）；
  归档去向＝台账事件（权威）＋按 README §6.2 落档＋知识库登记——**知识库晋升
  规则归本票**（05 Answer §6）。
- **边界**：台账事件＝任务事实的权威副本；长期记忆/知识＝可复用结论。什么进
  票据、什么进长期记忆由本票定，但**不得与台账状态互相矛盾**（任务状态只认
  台账投影）。
- **taskId ＝ provenance 根**（05 §1）：记忆条目与任务的对账以 taskId 为键。

## 来自 06 号票的输入（2026-09-12 裁定）

- **knowledge 权限面**：登记权＝**全员**保留（「谁产出谁登记」纪律）；读取＝
  全员＋直读面（W-1a）沿用；**登记不构成任务完成依据**（完成＝台账
  delivered）（06 §3）——晋升规则设计不得让知识登记反过来成为状态权威。
  物理命令化归 07。

## Answer

2026-09-16 用户 /wayfinder 逐票工作批收口：round 1 八问全裁「无异议」＝
按推荐授权（授权依据见 CHANGELOG 当日条目）。

### 1. 记忆三层 v2 定形（Q1）

三层＝①**岗位私有记忆**＝实例自身 workspace 内自由组织的笔记——L1 唯一
合法直写区，无 schema、无 host 服务、无专用工具；②**团队共享记忆不设独立
第三面**——任务事实走**台账**（事件投影，05）、可复用结论走**知识库**
（knowledge 命令面，07）；③组织常量（岗位卡/评测集/例程登记项）＝配置面，
不算运行时记忆。02 研究「团队共享＝仓库文件」与 06 L1 直写禁令的冲突由此
收编：共享写统一经 host 命令面，不开第四面。

### 2. 岗位私有记忆形态与存续（Q2）

形态＝自由 markdown 笔记；**不建结构化技能库**（07 已裁可执行规程两形态＝
岗位卡＋knowledge，02「可执行技能库」表述按此收编）。延续＝文件即记忆，
DSH session 残留不作记忆依据（turn baseline 纪律）。实例消亡＝私有记忆随
workspace 留存但**无备份/迁移义务**、岗位重建不保证继承（刻意低承诺，倒逼
值钱结论走 knowledge 晋升）；他实例读取走 W-1a 直读面（合法但不承诺）。

### 3. 写入分流判据（Q3）

三问分流：①本任务历史事实（谁/何时/何状态/何坐标）→**台账事件**；②换一个
不同任务仍成立（跨任务有效性试金石）→**knowledge**；③两者皆否的中间产物
→**taskId 键工件存档**（归档不删档）。模型推理过程任何面都不进
（fresh-context 复核隔离＝04 硬要求）。

### 4. 晋升规则（05 留给本票）（Q4）

时点＝任务关闭/归档流程内；触发人＝产出方（06「谁产出谁登记」）；强制性由
派单方在四要素简报 **output format 预声明**（同 acceptance 预登记惯例；全局
不设强制，「登记不构成任务完成依据」＝06 既定）。门槛三条：过**换模型
试金石**（条目是任务/环境/组织事实，非对某代模型行为的补丁）、**可独立
成立**（不读原任务轨迹即可用）、reused/supersedes 留痕照用。**不设强制
复核点**——知识登记不命中必审三判据（可逆可 supersede、非对外可见、旁路
沉淀非关键产出移交），保留可加审；「该登没登」不机械追偿，靠复用率 KPI
人工观测。

### 5. 失效规则（Q5）

台账：append-only 永不失效（05 既定）。知识：唯一失效机制＝**显式
supersedes/deprecated 登记**（append 语义、不物理删除、旧版痕迹保留；v1
机制照用）＋升级例程触发（08「做减法沉淀进 knowledge」同案登记）；**不做**
自动失效/自动打分/accessedAt 热字段（02 反例：embeddings-RAG 类自动机制）。
岗位私有：实例消亡即失效（§2 低承诺）。矛盾处理：知识与台账冲突**台账胜**
（05：任务状态只认台账投影）；知识与岗位卡冲突**岗位卡胜**（唯一源——07），
冲突条目须 supersede 收口。

### 6. 知识库在组织层件白名单的位置（Q6——08 张力收口）

**容器协议补进组织层件白名单**（本票即扩展裁定：register/search/supersedes
语义、索引协议是组织事实、过试金石）；**条目内容不在白名单**＝运行时产出
资产，逐条自负试金石（§4 门槛①），不属「岗位细节三处」（三处是配置面，
knowledge 是运行时增长面）。08「沉淀进 knowledge」由此获得白名单依据，
三处封闭性不破。

### 7. 移交与保留（Q7）

移交**只传指针**（taskId＋工件坐标＋知识 id），不复制内容（派单纪律 #16/#17
既定不转述不预填；02 D4 全轨迹、摘要式移交＝反例）；接手方按指针**拉取式**
自取，发送方不预载；工件保留＝**归档不删档、无保留期上限**（05「关闭不可
重开、归档不删档」延伸到工件面）。

### 8. 检索引导与复用率 KPI（Q8）

「开工先 search」引导住**岗位卡派生提示段**（07：岗位卡唯一源）——只写进
研究员/实施者等调研承载岗的卡片，不全员灌。检索面维持**索引级子串**（否决
embeddings/全文检索——02 反例；具体技术形态属实现轨道）。复用率 KPI 维持
**人工核对、不自动检测**，作为 13 号票「规格验收标准」的输入项（非自动化
验收判据）。

# 团队记忆与知识层

Type: grilling
Blocked by: 03, 05

## Question

跨回合/跨会话的组织记忆：岗位私有记忆、团队共享上下文、知识库（现 MVP）
三者的边界、写入/失效/晋升规则、在任务生命周期中的位置（handoff 工件与
记忆的关系——什么进票据、什么进长期记忆）。

## 来自 05 号票的输入（2026-09-11 裁定）

- **关闭与归档**：关闭前置＝判据通过＋复核点闭合＋产出登记（谁产出谁登记）；
  归档去向＝台账事件（权威）＋按 README §6.2 落档＋知识库登记——**知识库晋升
  规则归本票**（05 Answer §6）。
- **边界**：台账事件＝任务事实的权威副本；长期记忆/知识＝可复用结论。什么进
  票据、什么进长期记忆由本票定，但**不得与台账状态互相矛盾**（任务状态只认
  台账投影）。
- **taskId ＝ provenance 根**（05 §1）：记忆条目与任务的对账以 taskId 为键。

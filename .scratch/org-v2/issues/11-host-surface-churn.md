❓ **Q1** - **「会被代换」的判定规则：按失配后果分类，而非按面所在层**

三个候选口径：(a) 按宿主**层**分（前端面／服务面／配置面）——层与风险不对应，
前端既有响亮面也有静默面；(b) 按「宿主是否可能变」分——宿主一切皆可变，等于
全量上适配层，成本爆炸且与 07「不另起装载面」相抵；(c) 按**失配后果**分——问
一句：**「若宿主把此面改名或改形状，组织层会不报错但做错吗？」** 会＝**A 类
静默降级面**（必须：形状收敛到单一坐标的可替换适配层 ＋ **行为探针**）；不会、
失配即报错＝**B 类响亮面**（登记 ＋ 存在性/形状探针即可，可直用）；与宿主无关的
OS／语言契约＝**C 类**（`/proc`、`EventSource`、HTTP 标准——显式排除出登记表，
避免范围膨胀）。

F2 表已按 (c) 预分类：A 类＝组⑤（配置 id 静默 no-op，最危险）、组③（槽位
abdicate）、组②的 `ctx.get` 跳过支与 `ctx.baseUrl`、组⑥的日志面、组⑦的落盘
格式；B 类＝组①、组④、组⑥ 的 CLI、组⑦的命令面。

附：**版本探测的定位**——仅作**诊断字段**（探针报告与台账处置任务里记录宿主
版本号以便归因），**不作门**。依据：宿主今日 `0.1.5-rc.1`，rc 语义下版本号不
构成兼容承诺；本仓今日零版本约束，加版本门是新增一类需维护的契约。门只由行为
断言把守。

➡️ 采 (c)；A/B 分类入登记表，C 类显式排除并写明理由；版本仅诊断。

❓ **Q3** - **探针的结果语义与 fail-closed 分级**

三态 **PASS／FAIL／SKIP**，重点在 SKIP 与 FAIL：

① **SKIP 必须与 PASS 可区分且计数可见**——今日反例＝
`tests/locale-runtime.test.mjs:24-28` 的守卫（找不到宿主包即 `exit 0`），在
preflight 汇总行上与真 PASS 同形，且宿主改路径／改名时照样放行。修法（规程写明，
代码归 12）：探针三态分列，SKIP 必须打印原因与探测坐标。

② **SKIP 的许可面**：仅「本机未安装该宿主」的开发机／CI 场景允许 SKIP 且不阻断；
**bot 运行面与部署面上 SKIP 视同 FAIL**（宿主必在，此处 SKIP 只可能是探测路径
失效——把假绿堵死）。

③ **FAIL 分级（fail-closed 但不全停）**：默认＝**面级降级**——该面相关 op／工具
不注册、通道关闭，其余能力照常（沿用 07 已立「失效无文件直写降级」三分支：错误
回执／台账事件／进流程）；例外＝**整层拒载**，仅限组①「组织层身份面」（cordis
插件名与 `inject`、client bundle 协议、inject 清单）——这些面失配时无法安全降级
（要么不加载、要么错挂宿主 UI），故拒绝加载并按 09 口径纯告知用户。

④ **失效可见可归因**：探针 FAIL／运行面 SKIP 以 **class=duty 例程任务**落台账
承载处置（05 值守例程形态＋routineId 幂等；**不新增台账事件类型**，不扩 05 的
面），并按 09 投递面告知。A 类的存在理由就是消灭静默。

➡️ 采 ①②③④。

❓ **Q6** - **前端口径落地（Q4(b)「原生一致优先、功能可用兜底」）**

UI 形态本身 out of scope 维持（03 已裁），本票只定**适配边界与成本**。现状：
`lib/client.js` 以 `priority:-100000` 遮蔽 `sidebar`/`conversation` 两原生单槽，
消费约 40 个 primitives 具名导出与 `--dsw-*` token，并**读宿主 frame 私有 DOM
属性**——`lib/client.js:3064` `document.querySelector("[data-sidebar-collapsed]")`
（同处注释自承「面板 store 私有、无读取 API」，该属性是宿主全局唯一写入点）。

候选：(a) 只准依赖宿主**显式注册面**（slot 注册／inject、`ctx.layout` 公开动作、
`ctx.locale`、primitives 导出、`dsh.client.inject` 声明），**禁读宿主 DOM 结构与
样式钩子**；(b) 连 primitives／token 也须经适配层再导出——成本高、收益低（它们
本就是宿主公开 API）。

推荐 (a)：红线＝宿主私有 DOM／CSS 钩子禁入（今日 1 处越界登记在案，**代码处置
归 12**）；公开 API（slots/layout/locale/primitives/token）可直用但登记为 A 类面
（槽位 abdicate 是静默的）。

### 3. 探针结果语义与 fail-closed 分级（Q3）

① **三态 PASS/FAIL/SKIP，SKIP 分列计数并向用户可见**（打印原因与探测坐标）。
今日反例由此规程修掉：`tests/locale-runtime.test.mjs:24-28` 的存在性守卫
`process.exit(0)` 在 preflight 汇总行上与真 PASS **同形**，且宿主改路径/改名时
照样放行——假绿。探针报告的汇总行形如 `N PASS / M FAIL / K SKIP`。

② **SKIP 的许可面**：仅「本机未安装该宿主」的开发机/CI 场景允许 SKIP 且不阻断；
**bot 运行面与部署面上 SKIP 视同 FAIL**（宿主必在，此处 SKIP 只可能是探测路径
失效）。

③ **FAIL 分级（fail-closed 但不全停）**：默认＝**面级降级**——该面相关 op/工具
不注册、通道关闭，**其余能力照常**（沿用 07 已立「失效无文件直写降级」三分支：
错误回执／台账事件／进流程）；**例外＝整层拒载**，仅限组①「组织层身份面」
（cordis 插件名与 inject、client bundle 协议、inject 清单）——这些面失配时无法
安全降级（要么不加载、要么错挂宿主 UI），故拒绝加载并按 09 口径纯告知用户。

④ **失效可见可归因**：探针 FAIL／运行面 SKIP 以 **class=duty 例程任务**落台账
承载处置（05 值守例程形态＋routineId 幂等；**不新增台账事件类型**，不扩 05 的
面），并按 09 投递面告知。A 类的存在理由就是消灭静默。

不并入 `tests/`，三条依据：①`tests/run.mjs:42,48-54` 只报「N/N 个测试文件通过」，

# 01: 宿主适配面与宿主契约门

**What to build:** 组织层对 DSH 宿主的依赖按「失配后果」分类治理，使静默失效变成响亮失败。
落地：宿主适配面登记表（字段集＝面 id／宿主坐标／读取方式／类别 A|B|C／适配层归属模块／
探针 id／失效表现／末次结果指针；C 类面显式列出并标排除理由）；A 类面经可替换适配层把形状
收敛到单一坐标（宿主改名只动一处）并挂行为探针（真实调用一次、断言结果形状）；探针三态
PASS/FAIL/SKIP，汇总行形如 `N PASS / M FAIL / K SKIP`，**SKIP 必须分列计数且可见**；独立探针
脚本作为 preflight **第 4 道门**挂在冻结面门之后；修掉存在性守卫的假绿（其当前以零退出码在门
汇总行上与真 PASS 同形）；前端禁用宿主私有 DOM 与样式钩子，已知越界 1 处改造完成。宿主版本号
**仅作诊断字段、不作门**，门只由行为断言把守。

规格出处：`.scratch/org-v2/spec.md` §H（Implementation Decisions）与附录 A `V-A6.1`–`V-A6.6`、`V-A6.8`。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 适配面登记表在位，A/B/C 三类分类齐备，C 类面显式列出并标注排除理由（`V-A6.1`）
- [ ] A 类面经可替换适配层，形状收敛到单一坐标，宿主改名只动一处（`V-A6.2`）
- [ ] 探针三态，SKIP 分列计数并在汇总行可见；运行面与部署面 SKIP 视同 FAIL（`V-A6.3`）
- [ ] 门只由行为断言把守，宿主版本号仅记录为诊断字段（`V-A6.4`）
- [ ] 探针脚本作为 preflight 第 4 道门挂在冻结面门之后（`V-A6.5`）
- [ ] FAIL 默认面级降级；整层拒载仅限组织层身份面（`V-A6.6`）
- [ ] 存在性守卫假绿已修：SKIP 不再与 PASS 在汇总行上同形
- [ ] 前端只依赖宿主显式注册面；已知越界项（私有 DOM 属性读取）已改造；槽装载探针在位（`V-A6.8`）
- [ ] 全量回归与四道门 PASS

**遗留（不属本票）**：探针 FAIL 以 class=duty 例程任务落台账承载（`V-A6.7`）依赖任务台账面，
归 05 号票与其后的 14 号票收口；本票只保证 FAIL 响亮可见与面级降级。
